  otherwise print summary of given command.
      <string>  Name of command
  -v, --verbose=<0|1>  If specified, list console commands with given verbose level

free

heap

  execution

membench

flash-stats  [reset]

  reset`

version 
  The running firmware's version and build, then the IDF version and the chip

restart 
  Software reset of the chip

tasks 
  Get information about running tasks

top 
  Per-task CPU share over a window: top [seconds]

log_level  <tag|*> <none|error|warn|info|debug|verbose>
  Set log level for all tags or a specific tag.
       <tag|*>  Log tag to set the level for, or * to set for all tags
  <none|error|warn|info|debug|verbose>  Log level to set. Abbreviated words are accepted.

gpio  get <n> | set <n> 0|1 | release <n>
  Read or drive one GPIO, for bench wiring checks. set drives an output (the
  reply reads the pad back); release floats it again. Pins the board owns are
  refused.

light_sleep  [-t <t>] [--io=<n>]... [--io_level=<0|1>]...
  Enter light sleep mode. Two wakeup modes are supported: timer and GPIO.
  Multiple GPIO pins can be specified using pairs of 'io' and 'io_level'
  arguments. Will also wake up on UART input.
  -t, --time=<t>  Wake up time, ms
      --io=<n>  If specified, wakeup using GPIO with given number
  --io_level=<0|1>  GPIO level to trigger wakeup

deep_sleep  [-t <t>] [--io=<n>] [--io_level=<0|1>]
  Enter deep sleep mode. Two wakeup modes are supported: timer and GPIO. If no
  wakeup option is specified, will sleep indefinitely.
  -t, --time=<t>  Wake up time, ms
      --io=<n>  If specified, wakeup using GPIO with given number
  --io_level=<0|1>  GPIO level to trigger wakeup

join  [--timeout=<t>] <ssid> [<pass>]

  --timeout=<t>  Connection timeout, ms
        <ssid>  SSID of AP
        <pass>  PSK of AP

wifi_txpower  [<dbm>]

wifi_link

wifi_ps  [<none|min|max>]

wifi  [on|off]

        <ssid>  network to join and remember

wifi_forget  <ssid>

        <ssid>  network to drop from the store

wifi_known

dig  [-46] [@server] [-b address] [-p port] [-t type] [-q name] [-x addr] [name] [type]
  DNS lookup utility
       @server  The server to query
    -b address  Set the source IP (and optionally #port) of the query
       -p port  Set the port on the server to use, defaults to 53
       -t type  the resource type to query
       -q name  the domain name to query
       -x addr  simplified reverse lookup
            -4  use IPv4 only
            -6  use IPv6 only
          name  the name of the resource record to be queried
          type  the type to query, defaults to A if not provided

ip  [-s] [-f inet[6]?] addr(ess)?

  -s, --statistics  Output more info
  -f, --family=inet[6]?  protocol family

iperf  [-suVa] [-c <ip>] [-p <port>] [-l <length>] [-i <interval>] [-t <time>] [-b <bandwidth>]
  iperf command
  -c, --client=<ip>  run in client mode, connecting to <host>
  -s, --server  run in server mode
     -u, --udp  use UDP rather than TCP
  -V, --ipv6_domain  use IPV6 address rather than IPV4
  -p, --port=<port>  server port to listen on/connect to
  -l, --len=<length>  set read/write buffer size
  -i, --interval=<interval>  seconds between periodic bandwidth reports
  -t, --time=<time>  time in seconds to transmit for (default 30 secs)
  -b, --bandwidth=<bandwidth>  bandwidth to send at in Mbits/sec
   -a, --abort  abort running iperf

ping  [-W <t>] [-i <t>] [-s <n>] [-c <n>] [-Q <n>] [-T <n>] <host>
  send ICMP ECHO_REQUEST to network hosts
  -W, --timeout=<t>  Time to wait for a response, in seconds
  -i, --interval=<t>  Wait interval seconds between sending each packet
  -s, --size=<n>  Specify the number of data bytes to be sent
  -c, --count=<n>  Stop after sending count packets
  -Q, --tos=<n>  Set Type of Service related bits in IP datagrams
  -T, --ttl=<n>  Set Time to Live related bits in IP datagrams
        <host>  Host address

traceroute  [-f <first_ttl>] [-M <first_ttl>] [-m <max_ttl>] [-q <nqueries>] [-t <tos>] <host>
  print the route packets take to network host
  -f <first_ttl>  set the initial time-to-live used for the first outgoing probe packet
  -M <first_ttl>  set the initial time-to-live used for the first outgoing probe packet
  -m <max_ttl>  the maximum number of hops
  -q <nqueries>  set the number of probes per hop
      -t <tos>  the type-of-service in probe packets
        <host>  Host address
